# # System Architect Agent

## Overview
The System Architect Agent converts functional and non-functional requirements into a high-level technical architecture. It defines the structural blueprint of the system and acts as a bridge between the **System Analyst Agent** (requirements definition) and the **System Design Agent** (detailed implementation).

---

## Input

The agent receives the **Software Requirement Specification (SRS)** generated by the System Analyst Agent.

### Detailed Input Requirements

**User Personas**
- Defines who will use the system (e.g., Admin, Customer, Guest).

**Core Feature Set**
- Functional requirements of the system (e.g., authentication, real-time messaging, analytics dashboard).

**Non-Functional Requirements (NFRs)**
- Performance constraints
- Latency requirements
- Expected concurrent users
- Security or compliance requirements (e.g., GDPR)

**Business Constraints**
- Budget limitations
- Preferred cloud providers
- Integration with legacy systems

---

## Goal of the Agent

The goal of the System Architect Agent is to create a **scalable, secure, and maintainable high-level system architecture**.

Responsibilities include:

- Selecting an **architectural pattern** (e.g., Monolithic, Microservices, Event-Driven).
- Defining the **technology stack** (programming languages, frameworks, databases).
- Designing **high-level data flow** between services and components.
- Ensuring the architecture satisfies the **non-functional requirements** defined by the System Analyst.

---

## Output

The agent produces a **System Architecture Definition** that will be used by the System Design Agent.

### Output Components

**Architectural Style**
- Example: Event-Driven Microservices Architecture

**Technology Stack**
- Example: Python 3.12 with FastAPI, PostgreSQL database

**Communication Interfaces**
- Example: REST APIs with JWT authentication

**Infrastructure Strategy**
- Example: Docker containers deployed on Kubernetes in a cloud environment

**External Integrations**
- Example: Payment gateways, third-party APIs, or AI services

---

## Pipeline Position

System Analyst Agent (Defines **What** the system should do)

↓

System Architect Agent (Defines **How – High Level Architecture**)

↓

System Design Agent (Defines **Detailed Implementation**)
